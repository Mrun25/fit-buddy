# FitBuddy

A fitness companion UI with three planners: a workout planner, a meal planner and a water tracker. Frontend-only Next.js app, no backend or database - planner data comes from the static data files in `lib/`.

## Stack

Next.js 15 (App Router) + React 19 + TypeScript + Tailwind CSS + shadcn/ui

## Pages

- `/workout-planner` - build a workout plan
- `/meal-planner` - plan meals
- `/water-tracker` - track daily water intake

## Develop

```bash
npm install
npm run dev     # dev server
npm run build   # production build
npm run lint    # next lint
```
